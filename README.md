# Minhas Leituras

Aplicativo de organização pessoal de livros desenvolvido em Flutter e Dart para a disciplina de Dispositivos Móveis.

Permite cadastrar livros informando título, autor e status da leitura (Quero ler, Lendo ou Concluído) e consultar a lista de livros cadastrados.

Integrante: Caio Henrique Cid Rodrigues Cunha.

## Executar

É necessário ter o Flutter instalado.

```bash
flutter pub get
flutter run -d chrome
```

O cadastro e a listagem funcionam em memória nesta etapa. A remoção e a persistência local serão implementadas na próxima etapa.
