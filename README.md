# Minhas Leituras

Aplicativo de organização pessoal de livros desenvolvido em Flutter e Dart para a disciplina de Dispositivos Móveis.

O projeto tem como objetivo cadastrar livros, acompanhar o status de leitura e armazenar a lista no dispositivo.

Integrante: Caio Henrique Cid Rodrigues Cunha.

## Executar

É necessário ter o Flutter instalado.

```bash
flutter pub get
flutter run -d chrome
```

Nesta primeira etapa, estão disponíveis o modelo de livro e a interface de listagem. O cadastro e o armazenamento local serão implementados nas etapas seguintes.
